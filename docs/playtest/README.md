# Playtest kit (lab Phase 8, Checkpoint 8)

Run with **5+ players outside the team**, then retest the fixes with **2+ new players**.
Use codes T1, T2, … only. No names, faces or phone numbers in shared files
(Philippine Data Privacy Act, RA 10173). Testers under 18 need a guardian's consent.

## Files
| File | Who fills it | When |
|---|---|---|
| [CONSENT.md](CONSENT.md) | Each tester (signed copy kept privately, **not** committed) | Before playing |
| [OBSERVATION_SHEET.md](OBSERVATION_SHEET.md) | You, silently watching | While they play |
| [FEEDBACK_FORM.md](FEEDBACK_FORM.md) | Each tester (or the same questions in a Google Form) | Right after playing |
| [RESULTS.csv](RESULTS.csv) | You, typing each tester's answers | After each session |
| [ANALYSIS.md](ANALYSIS.md) | You + AI | After all sessions |

## Procedure (15–20 min per player)
1. **Prepare:**
   - Phone 1 with a **fresh install** (progress reset).
   - Phone 2 for the online match.
   - Both phones charged and on the same Wi-Fi.
2. **Brief in one sentence only:** "Please play as you normally would and say out loud what you are thinking." Do not explain the controls or the goal.
3. **Play** Levels 1–3 offline, then one online match with you on Phone 2.
4. **Observe silently** and fill in the observation sheet. Help only if they are stuck for more than 2 minutes, and write down that you helped.
5. **Form:** the tester fills in the feedback form right away.
